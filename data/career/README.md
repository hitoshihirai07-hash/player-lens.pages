# Player Lens 通算成績 データ更新手順

## 2026年の基準データ

- `career_record_batter_2026.csv`：2026年終了時点の野手通算（当年だけではない）
- `career_record_pitcher_2026.csv`：2026年終了時点の投手通算（当年だけではない）
- 野手CSVの `犠飛` は通算出塁率を2027年以降も再計算するため、既存の「現役通算_打撃」シートからPlayerIDで結合しました。ほかの数値は添付CSVのままです。
- 2026年の基準CSVは翌年以降も固定します。

## 2027年以降

1. **その年だけ**の成績を `career_record_batter_2027.csv` と `career_record_pitcher_2027.csv` のような新規CSVとしてこのディレクトリに配置。
2. `seasons.json` に次を追記（以下は例。ファイルが存在してから追加すること）。

```json
{
  "baseYear": 2026,
  "baseBatter": "career_record_batter_2026.csv",
  "basePitcher": "career_record_pitcher_2026.csv",
  "seasons": [
    {"year": 2027, "batter": "career_record_batter_2027.csv", "pitcher": "career_record_pitcher_2027.csv"}
  ]
}
```

3. 2028年以降は同様に`seasons`配列へ追加。過去のCSVには手を加えない。

### 年度ファイルに必要な列

- 野手：`選手ID, 選手名, 球団名, 試合, 打席, 打数, 安打, 塁打, 本塁打, 打点, 盗塁, 四球, 死球, 犠飛`
- 投手：`選手ID, 選手名, 球団名, 登板, 投球回, 自責点, 安打, 与四球, 奪三振`
- `安打`は投手成績では被安打数を示す（野手成績の安打と別物）。
- ほかの加算対象列（勝利、セーブ、ホールド、被本塁打など）は2026基準CSVと同じ列名にすると加算できます。
- 球団を移籍しても**選手ID**をキーにして記録を合算。年度ファイルでは同一年・同一選手IDの重複行を作らず、移籍前後を単年通算で一行にまとめてください。
- `.1`・`.2`は1/3回・2/3回として加算。
- 2027年のファイル名は `career_record_*_2027.csv` としており、`2027stats_batter.csv` のように打数・塁打が足りない簡易データをそのまま加算することはできません。必要な列を揃えた単年ファイルを出力してください。

**注意：** 2027年の年度CSVはシーズン通算ではなく「2027年単年」。2027年終了時点の新しい通算スナップショットを加算すると二重計上になります。

対象外：ポストシーズン、ファーム、日本代表戦、MLB。新入団選手が2026基準CSVにない場合は年度CSVから新規追加。
