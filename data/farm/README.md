# ファーム成績ページの更新

## 配置・対象

- 公開パス：`/farm`（Cloudflare PagesのHTML拡張子省略配信を使用）。
- 対象：年度ごとのファーム公式戦のみ。
- ファーム日本選手権、ファームプレーオフ、みやざきフェニックス・リーグはCSVへ混ぜない。
- 独自スコアとOPS・K/9・BB/9・K/BBはJavaScriptで計算。CSVに独自スコア列は追加しない。

## 年度追加

1. このフォルダへ以下の3ファイルを追加する。
   - `farm_batter_stats_2027.csv`
   - `farm_pitcher_stats_2027.csv`
   - `farm_standings_2027.csv`
2. 3ファイルとも「年度」列へ該当年を設定する。選手名／球団名が空の行は削除する。
3. `seasons.json` の `seasons` に `{"year":2027,"label":"公式戦・最終成績"}` を追加する。
4. 初期表示年度を変える場合は `defaultYear` を変更する。
5. 順位CSVの「球団」「地区」「順位」を確認する。地区所属と球団候補はこのCSVから自動で取得する。
6. 新年度を初期表示にする際は、検索・SNS向けの静的情報も `farm.html` のtitle、description、OGタグ、初期見出しと説明、`index.html` の案内、`sitemap.xml` の更新日で揃える。表示中の見出し・ブラウザタイトル・データ説明はJSが選択年度へ更新する。

2026年の地区構成・球団数はJSへ固定していない。別地区名も順位CSVから取得できる。
既存14球団の正式名称と略称は `assets/farm-data.js` で正規化。新球団や新名称がある場合は `aliases` に追加する。

## CSV列

野手：選手、球団、試合、打率、打席、打数、安打、本塁打、打点、三振、四球、盗塁、出塁率、長打率、最終出場日、年度。

投手：選手、球団、登板、防御率、勝、敗、セーブ、投球回、奪三振、四球、最終登板日、年度。

順位：年度、順位、球団、地区、試合、勝、敗、分、勝率、差。

投球回は `27.2` など野球表記のまま記録する（.1＝1/3回、.2＝2/3回）。欠測を0で補わない。
四球0のK/BBは「—（四球0）」と表示する。スコア計算内のみ「奪三振÷（四球＋1）」で補正し、ページの説明に明示している。

## 差分ZIPの反映

ZIPを展開し、フォルダ構成を保ったままリポジトリのルートへ追加・上書きする。
既存のファイル・フォルダを削除しない。このZIPはサイト全体ではなく変更ファイルのみ。
