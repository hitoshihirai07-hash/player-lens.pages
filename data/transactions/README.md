# NPB 入退団・移籍情報の更新

ページ：`/transactions`。Player Lens既存のHTML拡張子省略配信を使用します。

## CSV更新

このフォルダの `npb_transactions_2026.csv` を更新・上書きしてください。列名・列構成はそのまま使用します。

年度、発生日、球団、選手名、区分、契約区分、内容、元の移籍元・移籍先、備考、更新日。

- 「球団」は既存ページと同じ略称（巨人、阪神、DeNA、広島、ヤクルト、中日、ソフトバンク、日本ハム、オリックス、楽天、西武、ロッテ）。
- 「元の移籍元・移籍先」は表示用の原文です。分割・推定・補完しません。
- 「区分」「契約区分」の選択肢は選択年度のCSVから自動生成します。
- 発生日・更新日は `YYYY-MM-DD` または `YYYY/MM/DD`。画面では日付を `YYYY/MM/DD` に整えます。
- 最終更新日は、選択年度のCSV内「更新日」の有効な最新日付です。絞り込みでは変わりません。
- 備考が空欄のカードには補足欄を表示しません。表の備考欄も空欄にします。
- ドラフト指名選手はこのCSVへ追加しません。CSVの登録データのみ表示します。
- CSVはUTF-8（BOM有無どちらでも可）。カンマ・改行を含む値はCSVの引用符で囲みます。

## 2027年以降の追加

1. 同じ10列の `npb_transactions_2027.csv` をこのフォルダへ追加します。年度列も2027にします。
2. `seasons.json` の `seasons` に `{"year":2027}` を追加します。
3. 初期表示を2027年にする場合は、同じ設定ファイル内の `defaultYear` を2027へ変更します。

例：

```json
{
  "defaultYear": 2027,
  "seasons": [
    { "year": 2026 },
    { "year": 2027 }
  ]
}
```

2028年以降も同じ方法です。JavaScriptやページタイトルの年度変更は不要です。

## 表示・URL

- 発生日の新しい順。同じ日はCSV順。20件ごとのページ送り。
- 件数は全ページを含む絞り込み結果の総数です。フィルター変更時は1ページ目へ戻ります。
- 幅1,100px超は表、それ以下はカード。幅600px以下はカード1列。
- 絞り込み：年度、球団、区分、契約区分、選手名の部分一致。検索では空白・全角半角の違いを吸収します。
- URL：`/transactions?year=2026&team=巨人&type=自由契約`。
- `contract=育成` と `q=萩尾` にも対応。フィルター変更時にURLを更新し、再読み込みで復元します。
- データ読み込み失敗時は日本語のエラーと再試行ボタンを表示します。
